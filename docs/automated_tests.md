# Автоматизированные тесты

В `tests/test_booking.py` реализованы три сценария на Python и Playwright: успешное бронирование, негативный сценарий (превышение вместимости и отрицательное число участников) и проверка BUG-01 (прошедшее время сегодня). В тесте дефекта время браузера зафиксировано на 12:00, поэтому интервал 10:00–11:00 всегда в прошлом. Тест проверяет, что бронирование отклонено, и помечен `xfail(strict=True, raises=AssertionError)`: исправление дефекта приведёт к `XPASS` и ошибке набора, после чего отметку нужно удалить. Smoke-тест `tests/test_smoke.py` выполняется отдельно от этих трёх сценариев.

## Запуск

Из корня репозитория с Docker Compose v2:

```bash
docker compose run --build --rm tests
```

По умолчанию тестируется опубликованная страница. Для другого адреса укажите `BASE_URL`, доступный из контейнера. Без Docker установите зависимости и Chromium командами из README, затем выполните `python -m pytest`. Отчёт JUnit находится в `artifacts/junit.xml`, снимки и trace при падениях — в `artifacts/browser/`.

## Результат запуска

23 ноября 2026 года: **3 passed, 1 xfailed**, включая smoke-тест; время выполнения pytest — 27,30 с. Ожидаемое падение относится к BUG-01. Среда: Ubuntu 26.04.1 LTS на WSL2, тестовый контейнер Ubuntu 24.04, Python 3.12.3, Playwright 1.64.1 и Chromium 156.0.8078.4. Проверена опубликованная страница; требуются доступ к ней и Docker-образу при сборке.

Тесты подготовлены с помощью ИИ; сценарии и результаты доступны для проверки в файлах тестов и отчёте.
